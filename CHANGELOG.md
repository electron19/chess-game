# Changelog

## [1.0.0] - 2026-05-07

### Added
- Full chess game implementation for macOS 12
- All piece movements: pawn, knight, bishop, rook, queen, king
- Special moves: castling (kingside + queenside), en passant, pawn promotion (auto-queen)
- Check, checkmate, and stalemate detection
- Captured pieces panel with piece value sorting
- Board coordinate labels (a–h, 1–8)
- New game button
- Unit tests for board setup, move generation, check detection, en passant
